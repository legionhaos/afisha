# Telegram Mini App

Этот проект собирает существующий интерфейс из `../frontend/src/app/miniapp` и публикует только статические файлы в Telegram Serverless, не меняя обработчики бота.

```sh
npm ci
npm run build
TGCLOUD_TOKEN='<токен CLI из BotFather>' npm run deploy
```

Токен не сохраняйте в проекте и не коммитьте. Команда deploy публикует только `dist/`, не удаляя облачные обработчики. Доступный по HTTPS backend пока не настроен: приложение явно сообщает о недоступности каталога. Путь `/api/v1/events` требует отдельного подключения публичного API.
